## 8. 复现时一定会踩的坑（全部有独立出处）

1. **`__file__` 不存在**（Kaggle 用 `exec()` 加载；`main.py` 还有三级回退到 `/kaggle_simulations/agent`）。
2. **agent 是 `main.py` 里"最后一个被定义的 callable"**，不是叫 `agent` 的那个。
3. **一副牌只问一次**（`select is None`）⇒ 按局状态必须靠 `current.round` 变化重置。
4. **每局 600 s 预算在天梯上是每局重置**（2,406/2,406 局都是满的），而 PyPI 的 `kaggle-environments 1.33.0` 是整场一份。
5. **异常 / 非法动作 / 超时 = 整场判负**，不只是输一局；而公开 agent 普遍 `except Exception: 随机合法答案`，
   所以必须**数日志里的 `Traceback`** 才能发现"它在偷偷兜底"。
6. **引擎洗牌不可 seed**（内部 `std::random_device`）⇒ 只能做非配对的分层 bootstrap，不能做配对检验。
7. **攻击表必须在 load 时构建**：lazy 首调时 `sys.path` 已恢复 → `No module named cg` → 缓存空表 →
   所有招式 dmg=0，且**不报错**（有作者自曝"我们发布过这个 bug"）。
8. **`search_begin` 有两种签名**（`search_begin(obs,…)` 与 `search_begin(obs.search_begin_input,…)`），
   用错会被 `except` 吞掉 → 搜索永远返回 None，静默退化成规则。
